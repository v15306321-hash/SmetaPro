# Калькулятор и методика аналитики

> Формула калькулятора — открытый вопрос ТЗ (п. 26). Ниже — реализованный вариант, предложенный к согласованию.
> Код: `app/services/orders.py` (`compute_quantity`, `recalc`), `app/services/analytics.py`.

## Позиции заказа

Каждая позиция — одно из трёх видов: **материал**, **фурнитура**, **работа цеха** (сборка, монтаж и другие
основные работы). Позиция берётся из базы предприятия (название, единица, цена) или вводится вручную.
Позиции группируются по изделиям (разделам сметы: «Кухня», «Шкаф-купе»…).

### Количество

| Единица | Ввод | Количество |
|---|---|---|
| м² | высота × ширина (мм) × шт | `В × Ш / 1 000 000 × шт` |
| м.п. | длина (мм) × шт | `Д / 1000 × шт` |
| любая | число | как введено |

Количество округляется до 0,001.

### Стоимость (действует с 21.11.2026, согласовано с заказчиком)

```
себестоимость            = Σ количество × цена: материалы + фурнитура + технические работы
                           (распил, кромка, присадка, фрезеровка, покраска, сборка, доставка…) — без наценок
стоимость работы цеха    = себестоимость × наценка %        ← единственная наценка, «услуга цеха»
итого клиенту            = себестоимость + стоимость работы цеха + фиксированная доплата
оплата рабочим           = для каждого назначенного сотрудника:
                             % от «итого клиенту»  или  фиксированная сумма за заказ
                           — это расход цеха, клиенту НЕ добавляется
прибыль цеха             = стоимость работы цеха + доплата − оплата рабочим
```

**Пример.** Акрил 3 листа × 660.000 = 1.980.000; фурнитура 250.000; распил 150.000 → себестоимость 2.380.000.
Наценка 10 % → стоимость работы цеха 238.000 → итого клиенту 2.618.000.
Мастер на 5 % → 130.900; прибыль цеха 238.000 − 130.900 = 107.100.

Наценка и доплата копируются в заказ при создании; в заказе наценку можно изменить в боте («💵Настроить наценку»).
В PDF-смете позиции показаны по себестоимости, отдельной строкой — «Стоимость работы цеха», затем итог.

## Методика аналитики

| Показатель | Расчёт |
|---|---|
| Выручка (расчётная) | Σ итогов заказов, созданных в периоде (по местному времени, UTC+5) |
| Себестоимость заказов | Σ себестоимости материалов, фурнитуры и работ этих заказов |
| Затраты на материалы и фурнитуру | Σ себестоимости позиций «материал» и «фурнитура» |
| Стоимость работы цеха (валовая прибыль) | Выручка − Себестоимость |
| Оплата рабочим | Σ оплаты сотрудникам, назначенным на заказы периода |
| Производственные затраты | Σ записей раздела «Производственные затраты» с датой в периоде |
| Расчётный финансовый результат | Стоимость работы цеха − Оплата рабочим − Производственные затраты |
| Маржа | Показатель / Выручка × 100 % |

Расчётный финансовый результат **не является фактической чистой прибылью**: налоги, аренда, зарплаты и иные
обязательства не учитываются — это указано в интерфейсе. На тарифах со статусами заказов можно ограничить
выручку только завершёнными заказами.

## Учёт отходов и расхода (PRO, ENTERPRISE)

План формируется из позиций заказа (материалы и фурнитура, суммируются по позиции базы). Для каждой строки
вводятся фактический расход и отходы.

```
отклонение       = факт − план           отклонение %  = отклонение / план × 100
% отходов        = отходы / факт × 100   перерасход    = max(0, отклонение) × цена за единицу
сводный % отходов по заказу — взвешен по стоимости (разные единицы нельзя складывать напрямую)
```
