# Бесплатное размещение: Render + Neon — пошаговая инструкция

От нуля до работающих сайта и бота. Время — около 40 минут. Программировать не нужно, банковская карта не нужна.

## Что получится

```
Render (бесплатно)                         Neon (бесплатно)
└── furniture-estimate ── соединение ──►  └── PostgreSQL: все данные,
    сайт + кабинет + админка                  включая PDF-сметы, чеки и логотипы
    + Telegram-бот + фоновые задачи
UptimeRobot (бесплатно) — раз в 5 минут заходит на сайт, чтобы он не засыпал
```

## Что важно знать о бесплатном варианте

| Особенность | Как это ощущается |
|---|---|
| Сервис Render засыпает через 15 минут без посещений | С UptimeRobot (шаг 9) не засыпает. Без него первое сообщение боту после паузы ждёт ответа до минуты. Сообщения не теряются. |
| 750 бесплатных часов Render в месяц | Хватает на один сервис круглосуточно (в месяце до 744 часов). Не создавайте других бесплатных сервисов в этом аккаунте. |
| Neon: 1 ГБ данных | Около 20 000 PDF-смет вместе со всеми данными — надолго хватит |
| Neon: 100 часов работы базы в месяц | База «засыпает», когда ею не пользуются; проект настроен так, чтобы не будить её без нужды |
| Слабый сервер | Страницы открываются чуть медленнее, чем на платном тарифе |

Когда появятся платящие клиенты — перейдите на платный тариф за 5 минут без потери данных (раздел в конце).

## Шаг 1. Создайте бота в Telegram

1. Откройте **@BotFather** → `/newbot`.
2. Название, например `SmetaPro`.
3. Имя пользователя, оканчивается на `bot`, например `FurnitureEstimateUzBot`.
4. Сохраните **токен** (`7123456789:AAH...`). **Никому не пересылайте.**
5. Запишите имя бота без `@` — это `BOT_USERNAME`.

## Шаг 2. Узнайте свой Telegram ID

Откройте **@userinfobot** → «Start». Число **Id** (например `123456789`) — это `SUPERADMIN_TELEGRAM_IDS`.
С ним вы администратор платформы: подтверждаете оплаты, видите админ-панель.
Несколько администраторов — через запятую: `123456789,987654321`.

## Шаг 3. Код на GitHub

✅ Уже готово: код в ветке `main` репозитория https://github.com/v15306321-hash/SmetaPro

## Шаг 4. Создайте базу данных в Neon

1. Откройте https://neon.com → **Sign up**. Удобнее всего через GitHub или Google.
2. Создайте проект (**Create project**):
   - **Project name:** `furniture`
   - **Postgres version:** по умолчанию
   - **Cloud provider / Region:** **AWS — Europe Central 1 (Frankfurt)** — рядом с сервером Render
   - **Create**
3. На странице проекта нажмите **Connect**.
4. В окне подключения:
   - **Branch:** `main`, **Database:** `neondb`;
   - переключатель **Connection pooling** — выключите, нужна прямая строка;
   - скопируйте строку подключения. Она выглядит так:
     ```
     postgresql://neondb_owner:ПАРОЛЬ@ep-xxxx-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require
     ```
     Если пароль скрыт звёздочками — нажмите «показать» и скопируйте полностью.
5. Сохраните строку — это `DATABASE_URL`. В ней пароль от базы, **никому не пересылайте**.

Таблицы создавать не нужно: приложение создаст их само при первом запуске.

## Шаг 5. Зарегистрируйтесь на Render

1. Откройте https://render.com → **Get Started**.
2. Войдите через **GitHub** и разрешите доступ к репозиторию **SmetaPro** (можно выбрать «Only select repositories»).

## Шаг 6. Создайте сервис (Blueprint)

В репозитории есть файл `render.yaml` с готовыми настройками бесплатного сервиса.

1. В Render: **New + → Blueprint**.
2. Выберите репозиторий **SmetaPro**, ветка **main**.
3. **Blueprint Name:** `furniture-estimate`.
4. Render покажет сервис `furniture-estimate` (план **Free**) и попросит заполнить переменные:

| Переменная | Что вписать |
|---|---|
| `DATABASE_URL` | строка подключения из Neon (шаг 4) |
| `BASE_URL` | `https://furniture-estimate.onrender.com` (точный адрес проверим в шаге 7) |
| `BOT_TOKEN` | токен из шага 1 |
| `BOT_USERNAME` | имя бота без `@` |
| `SUPERADMIN_TELEGRAM_IDS` | ваш ID из шага 2 |
| `SUPPORT_TELEGRAM` | контакт поддержки для сайта, например `@your_support` (можно пусто) |

5. Нажмите **Apply**. Первый запуск займёт 5–10 минут.

`SECRET_KEY` Render создаст сам.

> **Если Render попросит карту для Blueprint**, создайте сервис вручную: **New + → Web Service** → репозиторий SmetaPro и заполните поля:
> - **Language:** Python 3, **Branch:** main, **Region:** Frankfurt, **Instance Type:** Free
> - **Build Command:** `pip install -r requirements.txt`
> - **Start Command:** `alembic upgrade head && python -m app.cli seed && uvicorn app.main:app --host 0.0.0.0 --port $PORT --proxy-headers --forwarded-allow-ips=*`
> - **Health Check Path** (раздел Advanced): `/healthz`
> - **Environment Variables:** шесть переменных из таблицы выше, плюс эти:
>   `PYTHON_VERSION=3.12.7`, `APP_ENV=production`, `BOT_MODE=webhook`, `DB_NULL_POOL=true`, `JOBS_INTERVAL_SECONDS=3600`,
>   `SECRET_KEY` = кнопка **Generate**.

## Шаг 7. Проверьте адрес сайта

1. **Dashboard → furniture-estimate**. Под названием — адрес, например `https://furniture-estimate.onrender.com`.
   Если имя было занято, Render добавит окончание, например `furniture-estimate-a1b2.onrender.com`.
2. Если адрес отличается от `BASE_URL`:
   - **Environment** → исправьте `BASE_URL` (с `https://`, без `/` в конце);
   - **Save, rebuild, and deploy**.

Адрес должен совпадать точно: по нему Telegram отправляет сообщения боту.

## Шаг 8. Убедитесь, что всё работает

1. **Logs** сервиса — должно быть:
   ```
   Running upgrade  -> 0001, initial schema
   Telegram webhook set: https://.../telegram/webhook
   Application startup complete.
   ```
2. Откройте адрес сайта — загрузится главная.
3. Отправьте своему боту `/start` — он предложит зарегистрировать предприятие.
4. Отправьте боту `/admin` — появится сводка платформы.
5. На сайте: «Войти» → «Войти через Telegram» → в боте «✅ Подтвердить вход» → откроется кабинет.

## Шаг 9. Чтобы сервис не засыпал — UptimeRobot

1. https://uptimerobot.com → **Register for FREE**.
2. **+ New monitor**:
   - **Monitor type:** HTTP(s)
   - **URL:** `https://<ваш-адрес>.onrender.com/healthz`
   - **Monitoring interval:** 5 minutes
   - **Create monitor**
3. Бонус: UptimeRobot пришлёт письмо, если сайт перестанет отвечать.

Адрес `/healthz` не обращается к базе. Поэтому сайт не засыпает, а база Neon спокойно «спит» и не расходует бесплатные часы.

## Шаг 10. Проверьте реквизиты и тарифы

Сайт → **Админ-панель** (ссылка внизу меню кабинета) → **Тарифы и реквизиты**.

- Номера карт HUMO, CLICK и UZUM BANK уже заполнены значениями из ТЗ — проверьте их и укажите получателя.
- Цены и лимиты тарифов меняются здесь же.

## Шаг 11. Пройдите сценарий от начала до конца

1. Бот → «💳 Подписка» → START → HUMO → отправьте любое фото как чек.
2. Вам придёт уведомление о заявке → `/admin` → выберите заявку → «✅ Подтвердить».
3. «⚙️ Настройки» → «💵 Наценки» → бот по шагам спросит наценки на материалы, фурнитуру и работу цеха.
4. «🧮 Новый расчёт» → имя клиента → телефон → количество изделий → формат изделия.
5. В карточке заказа: «📦Материалы» → «📝Настроить» → название → тип → размер листа → цена → количество листов.
6. «🛠Работа цеха», «💵Настроить наценку» → «📄PDF-смета».
7. В кабинете на сайте появятся заказ и смета.

Тестовую подписку можно прекратить: «Админ-панель → Заявки → Подтверждённые → Отметить возврат».

## Резервные копии

Все данные, включая сметы и чеки, хранятся в базе Neon. Делайте копию раз в неделю:

1. Установите на компьютер PostgreSQL client (`pg_dump`). Для Windows — установщик с postgresql.org, для Mac — `brew install libpq`.
2. Выполните, подставив строку из шага 4:
   ```bash
   pg_dump "postgresql://neondb_owner:ПАРОЛЬ@ep-....neon.tech/neondb?sslmode=require" -Fc -f furniture-backup.dump
   ```
3. Храните файл в надёжном месте (облако, внешний диск).

Восстановление в новую пустую базу:
```bash
pg_restore -d "строка-подключения-новой-базы" --no-owner furniture-backup.dump
```

## Свой домен (по желанию)

1. Render → сервис → **Settings → Custom Domains → Add Custom Domain** → `example.uz`.
2. У регистратора домена добавьте DNS-записи, которые покажет Render.
3. После статуса **Verified** (HTTPS Render выпустит сам) поменяйте `BASE_URL` на `https://example.uz` → **Save, rebuild, and deploy**.
4. В UptimeRobot поменяйте адрес на `https://example.uz/healthz`.

## Обновления

Любое изменение в ветке `main` — Render сам пересоберёт и перезапустит сервис, миграции базы применятся при запуске.
Перезапуск занимает около минуты; сообщения Telegram за это время не теряются.

## Переход на платный тариф (когда появятся клиенты)

**Самый простой путь — данные остаются в Neon:**
1. Render → сервис → **Settings → Instance Type → Starter** ($7/мес, понадобится карта).
2. **Environment:** `JOBS_INTERVAL_SECONDS=600`, `DB_NULL_POOL=false` → **Save, rebuild, and deploy**.
3. UptimeRobot можно оставить для мониторинга.

Сервис перестанет засыпать и станет быстрее. Если база вырастет больше 1 ГБ, можно перейти на платный план Neon.

**Всё в Render**, включая базу: `deploy/render.paid.yaml`. Перенос данных — `pg_dump` из Neon и `pg_restore` в новую базу, команды выше.

## Если что-то не так

| Симптом | Причина и решение |
|---|---|
| Деплой упал, в логах `connection ... failed` / `SSL` | `DATABASE_URL` скопирован не полностью: нужен весь адрес, включая `?sslmode=require` и пароль |
| `password authentication failed` | В строке нет настоящего пароля (звёздочки). Скопируйте заново в Neon → Connect |
| Бот не отвечает на `/start` | В логах нет `Telegram webhook set` → проверьте `BOT_TOKEN` (без пробелов) и `BASE_URL` (с `https://`, точный адрес) |
| Бот отвечает только через минуту | Сервис уснул — настройте UptimeRobot (шаг 9) |
| `/admin` → «Доступ только для администраторов» | Ваш ID не указан или указан с ошибкой в `SUPERADMIN_TELEGRAM_IDS` |
| После входа на сайте снова просит войти | `BASE_URL` начинается с `http://` вместо `https://` |
| Neon: «compute hours limit reached» | Проверьте, что `DB_NULL_POOL=true` и UptimeRobot проверяет именно `/healthz` |

Если не получается — пришлите текст из вкладки **Logs** (без токена и строки подключения).
