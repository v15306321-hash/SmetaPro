# Furniture Estimate

SaaS-платформа для мебельных мастерских, цехов и фабрик (рынок — Узбекистан, валюта — UZS):
расчёт стоимости заказов, PDF-сметы, производственные затраты, финансовая аналитика,
учёт расхода и отходов, сотрудники и роли, подписки с ручным подтверждением оплаты и реферальные скидки.

Два интерфейса — **Telegram-бот** (основной рабочий) и **веб-сайт** (публичные страницы + веб-кабинет +
админ-панель) — работают поверх **одного сервисного слоя и одной базы данных**.

## Состав

| Часть | Где | Что внутри |
|---|---|---|
| Сервисный слой | `app/services/` | Вся бизнес-логика: тарифы и лимиты, подписки, платежи, рефералы, калькулятор, материалы, затраты, аналитика, отходы, сотрудники, аудит, уведомления |
| Модель данных | `app/models.py`, `alembic/` | PostgreSQL (SQLite — для разработки), миграции Alembic |
| Telegram-бот | `app/bot/` | aiogram 3: регистрация, расчёт заказа, PDF, материалы, затраты, аналитика, сотрудники, оплата, рефералы, настройки, проверка оплат админом |
| Сайт | `app/web/`, `app/main.py` | FastAPI + Jinja2: публичные страницы, вход через Telegram, кабинет с аналитикой, админ-панель, REST API (`/api/docs`) |
| PDF | `app/pdf/estimate.py` | ReportLab, кириллица (DejaVu), логотип для BUSINESS+ |
| Тесты | `tests/` | 50 сценариев: сервисы, веб, бот (через настоящий Dispatcher), конкурентное подтверждение оплаты |

## Технологический стек и обоснование

- **Python 3.12 + FastAPI** — один язык для бота и сайта, общий сервисный слой без дублирования логики (ТЗ п. 18); автодокументация API (OpenAPI).
- **aiogram 3** — зрелый асинхронный фреймворк Telegram-ботов с FSM для пошаговых диалогов.
- **PostgreSQL + SQLAlchemy 2 + Alembic** — реляционная БД, транзакции, миграции. Критичные операции (подтверждение оплаты, списание лимита смет) — атомарные условные `UPDATE`, защищены от гонок (есть тест).
- **Jinja2 (SSR) + Chart.js** — быстрые лёгкие страницы без сборки фронтенда, хорошая SEO-индексация публичного сайта. Архитектура позволяет позже добавить SPA поверх `/api/v1`.
- **ReportLab** — генерация PDF без внешних бинарных зависимостей.

## Быстрый старт (локально)

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env          # укажите BOT_TOKEN, BOT_USERNAME, SUPERADMIN_TELEGRAM_IDS
python -m app.cli init-db
python -m app.cli demo --tg <ваш Telegram ID>   # необязательно: демо-предприятие с заказами за 7 месяцев
uvicorn app.main:app --reload                   # сайт: http://localhost:8000
python -m app.bot.runner                        # бот (polling) + рассылка уведомлений
```

Без бота войти в кабинет локально можно, включив `DEV_LOGIN=true` и открыв
`http://localhost:8000/auth/dev-login?tg=<ID>` (в production этот вход запрещён на уровне конфигурации).

TEST_DATABASE_URL=postgresql+psycopg://user:pass@localhost/fe_test pytest

## Служебные команды

```bash
python -m app.cli seed                 # справочники: тарифы, реквизиты, категории затрат (идемпотентно)
python -m app.cli make-admin <tg_id>   # выдать права суперадминистратора
python -m app.cli run-jobs             # напоминания/окончание подписок вручную
alembic upgrade head                   # миграции БД
```
